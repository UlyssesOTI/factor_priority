# Factor Priority

Настільний застосунок на Python (Tkinter) для визначення пріоритетності факторів методом ранжування.

## Можливості

- Побудова **матриці досяжності** для заданої кількості факторів із ручним введенням значень (0/1).
- Автоматична візуалізація **семантичної мережі** зв'язків між факторами.
- Розрахунок **рангів і пріоритетів** факторів на основі прямих і непрямих впливів/залежностей (показники s1–s4, X1–X4, XF).
- Побудова **дерев впливів і залежностей** для обраного фактора.
- Формування підсумкової **моделі пріоритетності факторів** у вигляді схеми.

## Вимоги

- Python 3.9+
- Бібліотеки: `numpy`, `networkx`, `matplotlib`

Встановлення залежностей:

```bash
pip install numpy networkx matplotlib
```

## Запуск

```bash
python Factor_Priority.py
```

## Порядок роботи

1. Вкажіть позначення факторів (наприклад, `X`) та їхню кількість.
2. Натисніть **«Створити матрицю»** та заповніть матрицю досяжності значеннями 0/1.
3. Натисніть **«Визначити ранги»**, щоб розрахувати ранжування та пріоритети факторів.
4. Оберіть фактор і натисніть **«Побудувати дерева зв'язків»** для перегляду ієрархії впливів/залежностей.
5. Натисніть **«Побудувати модель пріоритетності факторів»**, щоб отримати підсумкову схему.
